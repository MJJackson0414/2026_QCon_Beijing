## 開場

大家好，非常榮幸今天能夠在這裡跟大家分享過去一段時間我個人的一些思考。這（次）的（標）題取的是「模型之外」，但實際上——模型除了大模型（大語言模型）之外，還有很多其他模（型），（用「模型之外」）來（表達）我想講的（其實）不是特別準確。我主要的思考其實還是在說：**Outside LLM，我們會有什麼樣的發展跟定義。**

今天本來覺得……我這個 PPT 是今天凌晨四點才做好的，裡面還有很多很糙的地方，因為（我做得）非常晚。但後來我看到黃老師（黃東旭）也說他也是最近才做好，而且講了一個非常冠冕堂皇的理由——就是「我們這個（行業）發展得很快，所以你晚點做好的話，你的內容就會更（新）一點」——所以也緩解了一些我在做這個（PPT）時候的焦（慮）。

今天分享的內容主要分成六個部分。首先，在 vibe coding 的這個時代，我們去回顧一下「編程」是我們怎麼一步一步發展到今天的。接著，我們看一下過去幾年當中，Agent 的方法論有一些重大的變遷：從 Prompt、Context 走到 Harness（Engineering）。隨後，我們用一個人類智商測試的（心理學）理論——叫 CHC——來測量一下模型今天的智力水平；從模型能力來解釋「為什麼今天模型外面的腳手架越來越多、而不是越來越少」，這跟 Sutton 老爺子那個非常著名的「bitter lesson（苦澀的教訓）」的教誨是背道而馳的一個狀態。然後最後，既然看起來 scaling law 沒有辦法保證 LLM 直接走向（AGI），那麼接下來可能有兩個（在我個人看來）不同的道路可以走：一個是把 LLM 跟 evolutionary algorithm（進化算法）結合，看看在不做訓練的情況下，我們是不是有其他的路能通向 AGI；另一個就是「另起爐灶」——現在除了大語言模型之外最火的一個（方向）就是 World Model，但實際上 World Model 分成了非常多流派，它不像大語言模型今天已經（結構收斂）的狀態，我會從強化學習的角度來非常「輕點水」地過一遍，看看這條路（能不能走通）。最後我想用一下維根斯坦（Wittgenstein）著名的哲學論斷——他講的是「我們所處的世界是一個事實的總合，而非事物的總合」——去嘗試回答「模型之外」到底（會）產生什麼。

## 一、From Weaving to Programming：編程簡史

第一頁的標題是「From Weaving to Programming」。因為在準備的時候，我非常驚奇地發現：編程的體驗，跟寫（操作）編織機的體驗其實差不多。

這是世界上人類歷（史上）的第一個程序員——阿達（Ada Lovelace）。她在查爾斯·巴貝奇（Charles Babbage）的分析機（Analytical Engine）上寫下的第一個程序，是做伯努利數（Bernoulli number）的計算。她當時描述她在（巴貝奇的）分析機上做編程的體驗，就像她在一個提花機（Jacquard loom）上面去編織花和葉子的圖案一樣。大家可以記一下這個「提花機」的名字，因為我們很快就會意識到它會重新 revisit（回到）我們（面前），（帶來）一個類似的（隱喻）場（景）。

接著，我們可以看到：從早期 early programming 時代的（穿孔卡片 punch cards），到 machine code（機器碼），再到 assembly language（匯編語言），到今天大家日常使用最多的 high-level language（高級語言）——整個軟件對於世界的影響力，幾乎也可以說是隨著編程語言的進步而不斷進步的。從最開始二戰時期我們用（來）破解的 Enigma 機（恩尼格瑪密碼機）、去計算導彈的彈道，到整個互聯網的興（起），再到智能手機的興（起），可以說「without software there would be no modern world」——軟件的重要性毋庸置疑。

但是這個時代正在快速變化，這（種說法）已經是「過去時」了。或者應該說，今天「程序員的榮光」正在快速消散。本週一的時候，Linux 社區終於批准了 AI 生成的代碼可以進入到主流（內核）。我讀博期間是做操作系統內核的，我們當時的內核版號還是 2.6，天天在郵件列表裡可以看到（大量的討論）；那個時候光是內核編譯的配置選項就有數千行。所以我想，如果軟件世界（是）由一個一個的堡壘（組成）的話，那麼 Linux 內核應該是這個世界上最大、也是最後的堡壘——因為它足夠複雜、足夠重要，而 Linus（Torvalds）本人又足夠古板和「腿摳」（固執）。但沒想到就在幾天前，Linus 也鬆口了，他現在開始讓社區接受 AI 生成的代碼——只要有人為這段代碼負責。所以這個圖大家這幾天應該已經在網上看到了：手寫代碼可能在未來會變成一項「古法編程」的（技藝）。

## 二、The Golden Old Times：我們如何把自己逼到今天

11 年前、2015 年，我第一次參加 QCon 大會，體驗非常好。大家可以看一下 11 年前我們討論的是什麼：「敏捷之後是什麼」、「可擴展、高可用性的架構設計」，非常漂亮的一些（架構，AWS，very sexy）。從今天的視角來看——我知道大家應該對「大語言模型替代我們去寫代碼」感到很焦慮，所以我們回看十多年前時，會感到這是一個「golden old time（黃金年代）」。那個時候我們非常自信地在說「軟件正在改變世界」，而且主角毫無疑問就是程序員。但今天我們沒有辦法這樣說了。

而且不光是中國的開發者有這樣的感受，國外開發者的感受是一樣的。這裡我放了一個圖：是 OpenClaw 開（發者）聚會的時候，一個參與者跟 OpenClaw 作者（等）兩個人合影。合影時他最大的感受，他就說「the first time it feels like 2011（第一次讓人感覺回到 2011 年）」，大家聚在一起做這種（振奮人心的事情）。不管中美，程序員的焦慮是一樣的。

那我們怎麼辦呢？非常簡單的做法：你必須回到（暴力）。想要去捍衛程序員、或者人類的未來，怎麼辦？你去炸奧特曼（Sam Altman）他家，然後你還可以一週炸兩次——這是上週已經發生的事情。然後你炸完奧特曼他家，還可以再去砸 OpenAI 的總部，（有）（人）就非常有行動力，他已經這樣（做）了。如果我們實在離得太遠的話，你也可以在推特（X）上面猛噴它，給 OpenAI 造成一些輿（論壓力）。

但實際上我們會發現，這個「回（歸暴力）派」——我們今天對編程的焦慮和恐慌，（跟）當年的（紡織）工人是一樣的。但他們比我們更有行動力：他們真的組織起來，去打（砸）（紡）（織）（工廠）的機器了。這就是歷史上非常著名的「盧德運動（Luddite movement）」——他們有組織、有預謀地去砸了工廠裡面的紡織機器，因為（這些機器搶了他們的工作）。而他們打砸的機器當中，有一款就叫「Loom（提花機/織布機）」，這就是（前面）Ada Lovelace 說的「編程的體驗非常像在提花機（Jacquard）上面去提花」的那種感受。

所以我在發現這個巧合的時候，有一種「所有命運中的饋贈都在暗中寫好了價格」的感覺，而你很難走出這個命運的輪迴。因為今天我們發現：面對 AI 的時候，作為程序員，我們其實能做的並不比 200 年前的紡織工人高明多少——而且他們還比我們更有錢，（更懂得）組織起來，對吧。

## 三、Agent 方法論的變遷：Prompt → Context → Harness

回顧一下，我們今天是怎麼一步一步把自己逼到這個地步的。過去三到五年當中，Agent 的構造出現了大概幾個主要的方法論：**Prompt、Context、Harness（Engineering）**。我非常粗糙地把它們放在同一個架構面上，說明一下各自的差異。

**Prompt** 更多關注「模型有沒有理解你的需求」，面臨的情況是：同一個模型，換一種說法，效果可能會差很多。**Context** 相比的話，更關注「模型有沒有拿到足夠正確的信息」——在（這個層面）我們會給模型很多外部信息，包括 web search、包括（工具）、包括 database 之類一堆的東西。然後到 **Harness** 的時候，它的注意力又更進一步：從「輸入側」變到了「輸出側」——即模型在真實的執行裡，能不能持續地做對。所以我個人是非常粗糙地這樣分，但實際上這三個概念幾乎可以說是並行發展的，並沒有一個嚴格的（時間）上的區別，而且隨著大家實（踐）的進行，它們的意義上有很多可以重疊的地（方）。

### Prompt 時代

首先大家有印象，Prompt 的時代，也就是三年之前吧，非常像「魔法」：你說出一些 magic word（咒語），模型突然就能工作了；你不說，它就是不行。比如你說「幫我總結這篇文章」，它就什麼都幫你總結不出來；但是如果你說「請以資深技術編輯的身份，用三段結構總結這篇文章：先講核心觀點、再講（論證）方式、最後講（局限），每段不超過 150 字」——它就能做得很好。它有一大堆那個時代的技巧，但是我們這個社區發展實在太快了，估計大家可能都忘了：在 Prompt 那個時間，我們在（費盡）心（思）去調整模型、按照我們的想法去走。但不管怎麼做，Prompt 的能力局限在於：它只能依賴模型內部已經具備的知識——更具體說，就是 Prompt 什麼時候（觸發），你就只能（調用）它之前的知識。

### Context 時代

然後 Context 則是大家後來意識到：（要提供）「會影響模型當前決策的信息的總合」。而且大家更多地認識到，模型本質上是一個「特定（token）的發生器」，然後我們就可以把系統的規則、安全的約束、還有用戶的輸入這些都丟給它，然後對 context 進行管理。系統必須在調用的時候把這些正確的信息送進去，（該）暗（示）的（暗示）、（該）分層的分層，在正確的時（刻）給（到）。這個時候，Context 就能比 Prompt 更好地激發模型去做（我們想要的）能力。但這個時候問題就在於：即使你給了全部正確的信息，模型並不能真正地執行它——它可能跟一個初級的程序員相比，執行的（可靠）度還有很大的差（距）。

### Harness 時代

所以我們就走到了今天 Harness 的方法論。這個版本的答案是：模型在真實執行裡能不能持續地做對——就是「馬具」嘛。我們會把大模型當「馬」，然後外部的約束、引導的系統就是「馬具」：模型不僅負責（提供）信息，還負責駕馭（整個）過程。

我在這裡使用一個——這是 OpenAI 給的一個「long-horizon task（長程任務）」的介紹。網上關於 Harness 並沒有一個非常好的定義，OpenAI 其實也是在（各說各的）。我們這裡用了一個 B 站用戶總結的、非常好的（框架），它把 Harness（Engineering）分成了六個層次：**Context Engineering、Tooling / Agent-Computer Interface、Agent Loop / Orchestration、State-Memory-Externalized State、Evals-Feedback-Observability，以及 Constraints and Recovery。**

我們看到，在整個以（模型）為中心的版圖裡面，我們在外面搭了非常複雜的一個腳手架。這個腳手架包含了以前我們在 Prompt 時代、還有 Context 時代做的所有努力；同時又加上了「當模型真的去走向真實世界之後，它可能會造成的破壞」——我們又必須（去）評估。這就是今天整個的大的途徑。

這裡我想非常強調的一點是：模型本身，它工作起來很像一個 pure function（純函數）。所以它整體跟外界交互的一個核心，是一個 memory system（記憶系統）——我們要能夠幫助模型記錄「今天你到底走到（哪一步）」。只有在這樣一個機制的情況下，我們才有可能讓模型真正去做一些困難的問題。

## 四、用 CHC 理論測量模型的智力

今天雖然大家在口號上面還在提「走向 AGI」——為了融資、為了上市，各個（公司）不管（中）美都是一個樣子。但是我們可以看到：方法論雖然越來越複雜了，但實際上「bitter lesson」是越來越被背道而馳的。那我們為什麼會走向這樣的道路？為什麼外面的腳手架變得越來越複雜、而不是越來越簡單了？

大家可以稍微回顧一下：至少在兩三年之前，我們還在想著用一個通（用）的模型去解決所有問題——我們要統一生成和理解、我們要統一各種模態。但是今天大家不提這些了。如果你去看（Claude）Code 的代碼的話，這個代碼幾乎全部都是各種各樣的 corner case。應該說，Anthropic 跟 OpenAI 已經完全背棄了「（大一統）」理想紀念（碑），走向了截然不同的道路。所以我們就在想：為什麼沒有模型（能）真的在 LLM 這條路上走下去？

首（先），有一篇做得非常好的文章，名字我（就不）（念）了，它有幾十個作者、屬名（很長），這些人（很多知名的）都參與了。他做了一件很簡單的事情：人類的智商測試——大家應該都非常熟悉。這個智商測試的基礎是一個心理學理論，叫 **Cattell-Horn-Carroll（CHC）**。我們平常做的那些「找規律」啊、「在圖裡面做拼圖」的這些，實際上基於的是一個「流體智能」的度量。

整個 CHC 理論其實分成三層：最上面一層，它認為我們人類有一個 general intellectual ability（一般智力，g）；然後在這個上面再分，我們可以把它進一步分成「流體智能（Gf）」和「晶體智能（Gc）」；再進一步往下分，會分成讀寫、數學、法律、醫學……巴拉巴拉一堆其他的（細分）智能。

最重要的一點，是想說明白「流體智能」跟「晶體智能」的差別。流體智能指的更多是一種「天生的」——這個人他的智力水平高或低，這個能力不會隨著他接受的教育水平高低而發生變化。而晶體智能正好相反：晶體智能，你完成一個任務可能需要這個任務很多相關的知識，它正好是隨著 education（教育）或 experience（經驗）增加而增加。

有了這個概念之後，我們今天可以再拿回來對比 LLM 跟我們人類之間的差別。你會發現：**LLM 在晶體智能的所有領域上，已經全面超越人類了**——沒有任何一個人類能夠在「被知識（覆蓋）、用這些知識」的這種（賽場）上跟它比。但是它在「流體智能」上仍然處在一個很差的結果上面。

這是幾位作者比較全面地、在通過十個不同的分項上，對主流的 GPT-5 做了一個測試之後得出的結論。總共分了十個（分項），其中大概有三四個表現比較好、還有三四個表現中等。好的部分我們用綠色標識出來、中等的用黃色、以及表現最差的部分。大家可以看，最差的部分實際上跟我們想的正好相反——它最差的部分表現在 memory（記憶）上！這就是我們前面在 Harness 那裡專門提出來的：模型需要一個外在的 memory system，才能去做（那些需要）long-term memory 的任務。

它表現比較好的部分非常容易理解：讀寫的能力、知識存取的能力，以及那些「結果能夠實（時）去 verify（驗證）」的（任務），比如數學——這是過去兩年中突飛猛進的結果。它表現一般的部分，是像 audio processing（音頻處理）、on-the-spot reasoning（即時推理）——比如有了 O1 之後，大家的 reasoning 確實（進步了）；working memory 整個上下文提升之後也變好了不少；以及 visual processing，隨著多（模）態模型的進展也有很大進展。但是表現到今天為止、到這篇文章發布為止仍然很差的部分，是 long-term memory 的 retrieval（檢索）和 storage（存儲）。

大家可能會奇怪：為什麼模型這樣一個「能夠記憶人類全部知識」的工具，會在 memory 上表現得很差？這是因為模型跟我們人類的智能有一個巨大的差別：**我們人類是「推（理）（學）（習）一體」的。** 如果有人來問你一個問題，你在推理、告訴他答案的過程當中，你其實也在從這個當中學習——學習的結果會先進入你的短期記憶，然後你睡一覺之後，它慢慢會進入你的長期記憶，你慢慢就會再進步。但（模型）不一樣：你問任何問題，只要他不是把你問的這個問題重新訓練進去，你問他一萬次，它也不會有任何進步。

所以在這個意義上講，模型的 long-term memory 的 retrieval 跟 storage 是做得非常（差）的。這一點其實非常非常重要，因為今天模型這種「訓（練）（推）（理）分開」的方式、這種範式，其實阻礙了模型高效地往下探索。我個人認為這是 scaling law 今天「撞牆」的一個非常重要的原因——因為我們人的學習效（率）比於模型可能要（高）好幾個數量級。「推（理）（學）（習）一體」很有可能是我們（人）跟模型在智能上本質差異的一個表現點。

## 五、模型之外的兩條路

現在很明顯，這（條路）直接走不通 AGI 了。那麼接下來會有兩條路。

### 路一：LLM + 進化算法

第一條路就是：在模型之外去找。我們把 LLM 跟 evolutionary algorithm（進化算法）加起來的話，它是不是能給我們一些驚喜？今天在座各位可能在公司都已經是中（層）了，所以年紀不會太輕、跟我一樣，所以你們可能在上學的時候就學過「遺傳算法」。它在計算機發展歷史上很多次被 revisit（重提），因為它看起來就非常 fancy——能夠去突破一些「人類憑藉智力去 design 做不到、而憑藉大自然最暴力的篩選機制能夠做出來」的（東西）。所以這個 idea 反覆被 revisit。

最近一次最好的 revisit，是 Google 在去年 5 月份發的一篇文章，叫 **AlphaEvolve**。它非常簡單地用 LLM 去替換掉了傳統遺傳算法的 mutation（變異）過程，數量級地提升了遺傳算法當中最被人詬病的「變異」的效果——因為大語言模型可以理解你的語（義），所以它能理解你變異出來的這些不同的 candidate（候選）哪個好哪個差，各種 operator 都是用大模型去做的。可以看到，去年推出這個結果之後，它在數學分析、幾何、還有組合數學方面，都比之前的人類結果有一個提升。這是（之前）純（憑）大語言模型（做不到的）。

當然這是去年的工作，今年大廠可能又做出來一些 fancy 的東西，因為外面（在卷）。但去年的話，應該說它是（給了）這樣（幾）個例子，說「大模型超過了人類的（知識）」——因為之前大模型其實在「（蒸）（餾）整個人類社會的知識」，你通過蒸餾的話，你永遠不可能超過（老師/知識源），你只能無限接近；但 AlphaEvolve 是第一次做到超過這一點。這是為什麼我們會注意到這篇工作，並且花了相當的時間在後面做一些（跟進）。

然後我們選擇在這個方向上往下工作的一個主要領域，叫 **symbolic regression（符號回歸）**。簡單講就是：我有一大堆數據，我可不可以直接從這個數據裡面探索出來——它背後是不是有一個很漂亮、很簡潔的 mathematical equation（數學方程）可以描述這個數據。歷史上最著名的例子，就是第谷（Tycho Brahe）花了三四十年、一輩子去積累恆星運動的數據，然後開普勒（Kepler）拿著這個數據提出了非常多的假設跟猜想，最終用三條簡潔的「開普勒行星運動三定律」，總結了第谷觀測的所有數據裡面的（規律）。那麼今天 symbolic regression 這個任務的定義，就是希望做到類似的事。

之前的 SOTA 方法，是（有人）首先提出這個 benchmark：用 LLM 來做 symbolic regression，它自己在它提出的這個 benchmark 上大概做到了 11 點多的效果，其實對於初創的（工作）已經做得很不錯了。然後今年早些時候的（另）一篇文章大概做到了 16。因為大家可以想，這個任務丟給你的不過就是這些數據本身，然後你要去產生這個 math equation，還是一個挺有挑戰的事情。然後我們去做了一個新的方法，叫 **Function（Evolve）**。我今天不能談這個方法的任何細節，因為我們的 paper 還沒有放，但大概在 NeurIPS 之前我們就會把它放出來。今天我只能「吹牛」，講我們這個方法的效果有多麼「炸裂」。

這是之前的——這裡是 LLM-SR 的四個主要領域，分別是生物、化學、物理，以及材料科學。之前的 previous 方法大概平均分在 20 分左右，而我們的 FunctionEvolve 基本上可以說是「end the game（終結遊戲）」。我們能做得這麼好的非常重要的一點，是我們是一個 **structure-guided evolving**：我們把這個領域本身的內在結構，想辦法嵌入到了整個 evolving 的過程當中。使得相比於 AlphaEvolve 時代——它不只是說用 AlphaEvolve 去在語（義）上面改善傳統遺傳算法的低效，更進一步：不同的領域因為其內部有不同的規律，是不是可以把這些規律「顯式地」告訴大語言模型，使得它在 evolving 中更加高效。我們這個目前給（我）證明了是（有效的），而且是量級式的提升——甚至說如果已經到了 90 分的話，可能對於這個任務來說，我們已經做到了「版本答案」。

### 路二：World Model（另起爐灶）

這是「LLM + evolving」的一條路。另一條路就是完全「另起爐灶」——我們拋棄掉 LLM 的所有假設，然後走向這一段時間已經非常火（的）、應該（大家）耳朵都聽出繭來的 **World Model（世界模型）**。這裡我參考網上一篇做得非常好的文章，它把整個 World Model 分成了五個不同的時期。

第一波我們就不算了，因為早期的時候，其實 World Model 跟 reinforcement learning（強化學習）並沒有分得很開。但從 18 年開始，《World Models》這篇文章（David Ha 跟 Schmidhuber 兩位）發表，重新開始讓「World Model」這個詞進入（大家視野）。我其實非常早就注意到這件事，大概文章發表的第二天我就看到了。當時的評價，是覺得它（理念很好）——雖然他的理念非常好，他就是說：我是不是可以在「不用那麼多現實世界數據」的情況下、就像人會做夢一樣，讓模型也去做個夢，在這個夢裡面訓練自己來獲得更好的性能。所以它的名字也很簡單，就叫 **Dreamer V1**。

但是他做的這個 task 正好——它這個 task 是 ViZDoom 上面的一個 task，非常簡單：你面臨一大堆小怪物，然後你可以發射火球去打這些怪物。我當時就很奇怪：他為什麼去選擇如此簡單的一個（任務）？對於（測試）World（Model），如果你是一個（開創）性的新方式，你不應該在你的 demo 上展示一個更能夠顯示你 power 的領域來做嗎？

因為我們當時正好在做這個相關的比賽。它（用的）Doom 這款遊戲，是世界上第一個第一人稱射擊遊戲，由傳奇（程序員）John Carmack 開（發），他在 93 年的時候（做出來），成為當時最爆款的遊戲。後來他把這個遊戲開源出來之後，大家可以在這上面構建智能體的平台，就是 **ViZDoom** 這個平台。順便提一下，2023 年他（John Carmack）跟 Richard Sutton 兩個人一起合作開了一個叫 **Keen Technologies** 的新公司，這個公司認為「大語言模型絕不是最終的答案，一定會有更加簡潔、更加好、但我們還沒發現的方式來走向 AGI」。但這個公司非常低調，既不融資也不發任何新聞稿——這是我在他公司官網上（看到的）就一句話：「my aged effort, no information is available」。

我們當時在這個（ViZDoom 比賽）上面做，運氣比較好，打到了冠軍（TSAIL，清華大學 & 騰訊 AI Lab），所以我們對這個遊戲、對這個智能體的 benchmark 本身理解得非常深。所以我們在研究 World Model 這個第一天的原始文章時，就覺得很奇怪：為什麼他這個遊戲裡面其實場景非常多，卻不去選擇一個更能證明自己的場景來做？

這個是當時我們拍的一個紀錄片，介紹我們怎麼去用強化學習的方法先解決 ViZDoom 這個場景。今天放在這（還）有一個原因：一會大家可以看到後面有一個年輕人——翁家翌（Jiayi Weng），今天他在網上應該已經很有名了。他現在（2022 年六月份）加入了 OpenAI，在 OpenAI 裡面做的就是強化學習的框架這部分。這個框架最開始是 2018 年那時候，他在清華、我們一起去做這個比賽，然後為了這個比賽做了一個小的（強化學習）平台——這個小平台就是今天大家還能在 GitHub 上看到的 **Tianshou（天授）**。加入 OpenAI 之後，他就在天授的代碼上面改了一些基礎（，成為 RLHF 框架的雛形）。今天大家已經對 RLHF（RL from Human Feedback）非常（熟）（悉），但那個時候它還是一個不是很（起眼）的（工作）。所以非常有趣——你可以看到整個世界的（脈絡）非常緊（密），各種各樣的技術在早期是（緊密交織）的。

但是我們去測試了之後，發現它效果很差。這時候就導致我個人整體對於整個 World Model 這個分支（產生懷疑）——因為我 18 年就開始關注它了，花了很多時間去 try 當時 18 年的 World Model 各種操作、包括後來（一）系列（簡化）。我個人就很懷疑：World Model 真的是除了 LLM 之外最有希望走向 AGI 的道路嗎？它們會真的帶給我們更 smarter policy、更強的 control capability，或者 ultimate（更高的）智能水（平）嗎？我個人（覺得）可能不是。因為如果我們非常簡（單）、不去看那些 fancy 的 word、不去看那些 story 的話，我們僅僅簡單地算的話，你會發現 World Model 的競爭對手非常多：給機器人做訓練、或者給（自動駕駛）的話，我們可以用 game engine（比如 Unreal Engine）、可以用各種各樣的 simulator，繼續（用）LLM、或者今天的（各種手段），或者 generative game engine 加在一起——他們都可能在 World Model（能做的事）上，以更低的價格做到比 World Model 更好的效果。所以這是在 V1 的時候（我的看法）。

等到 World Model 2020 年之後，大家的問題就產生了一些變化：隨著 World Model 的發展，它是不是可以最終達到 human performance？當中最好的 SOTA 仍然是在遊戲上面。前面第一天開山做 World Model 的 Dreamer V1，到了後兩三年之後做了 V2，他終於從一個簡單的 ViZDoom 遊戲擴展到了整個（更多遊戲）；但仍然是在遊戲裡面，並沒有更多現實世界當中的應用。這是那兩年的主要進展。

然後就是 World Model 領域最大的「吹手」——他在這個前後（那段時間）發表了 **JEPA**，以及後來產生了一系列重要的變種：I-JEPA、V-JEPA 系列。JEPA 系列的 idea 非常簡單粗（暴）：它認為大語言模型的思維模式跟人類的思維模式完全不一樣。如果我們想要走向 AGI，且認為人類是達到了 AGI 的一個物種的話，那麼最直接的道路就是模仿人類——模仿人類的腦區裡面到底是怎麼工作的。它很簡單地把整個 JEPA 系列的架構分成 configuration、short-term memory、long-term memory、perception 一大堆的結構。大家應該對他（LeCun）非常（熟悉），因為他經常在網上「噴」、有很多觀點，然後最後（從 Meta）丟了工作，現在回到歐洲去開了一個新的公司。但他畢竟拿了圖靈獎，所以他拿了 10 億美元在做新的 World Model 的（創業）。我其實個人非常喜歡大家都去堅持自己的（方向）、去做 diversity（多樣性）——不要所（有人）都走向（同一條路），那是有害的，非常（不）（好）。

接著介紹一下我們當時自己也做的一個類似工作，比困（LeCun）「另起爐灶」要保守得多。我們當時的想法非常簡單：在那個時候，YOLO（YOLOv3–v7）這些 object detection 的工具已經做得非常好了，所以我們就想，其實沒有必要把整個 planning 跟（感知）（重新）結合起來。所以我們希望去結合強化學習領域兩個最重要的思潮：一個是 model-based、一個是 model-free。然後我們簡單地用這種 object detection 之類的 neural network，把外部複雜的 pixel-level 的世界抽象成一個一個的「命題邏輯」；然後我們可以在這個邏輯裡面——這是一個 highly compacted world——你可以在這裡面去跑 value generation（價值生成），去拿到 optimal 的 policy；拿到這個 optimal policy 之後，再反向映射回真實的世界，讓它去跑。這樣的話，你的模型——雖然我們沒有辦法證明這兩個 f 函數（跟它的反向 f 函數）是完全（一一）對應的，因為你付出的代價是極大地減少了直接的計算量——但它實際的效果表現得還可以，而且整個框（架）讓模型本身的行為高度可預測：你甚至可以在它抽象出來的這個 proposition（命題）的 world 裡面去編輯它，而直接影響模型的（行為）。

接著就到了第三波浪潮。第三波浪潮，社區對 World Model 提出了更高的要求，也發展出更多效果：就是說 World Model 本身可以真的跟現實世界去交互。這裡是 CS:GO 這個遊戲的畫面。這個時期的代表工作是 **Genie**——我們真的可以明顯看到，相對於 Dreamer 時期打那些 2D 橫版通關遊戲，在 Genie 的時代，它確實可以去生成這種級別的視頻。然後這個是非常著名的 **GAIA-2**（駕駛世界模型），它把世界各地行車的數據合在了一起，然後希望去（生成）一個對 autonomous driving 領域非常重要的（世界模型）——把各種各樣的 corner case 都（生成）完之後，可以去取得比（傳統仿真）之類的模擬器更好的效果。

然後接著就到了第四（波），也是（近期）：它是 Google 這邊的 **Genie 3**。Genie 3 提供了一個非常有趣的產品，大家可以看到，相當於你做一個玩家，你要操控（角色）在整個這個世界裡面去進行探索。所以他希望讓 World Model 真的去通過這樣一個「acting（互動）」的方式，去跟 real world 發生真正的交互。以及最近另外一個值得放在這裡、值得一提的是：World Model 領域兩個最大的（融資）——一個是（LeCun）回到歐洲去做的（他的實驗室）；另外一個名字就叫 **World Labs**，是我們華人女性科學家李飛飛（Fei-Fei Li）老師做的。這個 World Labs 也融了 10 億美元天使（輪）。但他的道路更（走）到了完全不同：它走的是一個 **3D Gaussian Splatting（3D 高斯潑濺）**重建的道路，好處是完全（可以）用（它）去（重建）背後這個 structure，然後把它渲染出來，也是另外一種 World Model 的道（路）。

最後介紹一下我們自己在 World Model 上面的一些（工作）。我們博世是一家汽車零部件供應商，所以 ADAS（自動駕駛輔助系統）一直是我們最高優先級的一個關切。自動駕駛領域，收集這種編輯（邊界）的案例、罕見（長尾）場景，對訓練跟評估至關重要，但這些東西非常難以收集。所以我們主要的一個目的是：針對這種特殊的、難以收集的（長尾）場景，我們可以去對它進（行）直接手工的 editing，然後把手工之後的結果再放回這個場景去，把這個場景重新生（成）出來——這樣各種各樣的 corner case 就都可以去做了。這也是 follow 了 Google DeepMind 去年的一個工作，它提了一個新的概念叫 **Neural Assets**：這裡面就是簡單地把一個白色的麵包車，編輯成我們希望變的一個灰色車的樣子，其他部分保持不變。這樣的話，理論上這個技術我們可以無限地去生（成）我們需要的場景。然後我們在這個基礎上更進了一步，比它生成的效果要更加逼向真實，而且可以從多個角度支持這件事情。這是我們希望去實現的一個效果——一個 compositional（可組合）、egocentric（第一人稱）的 world model。

### 對 World Model 的個人判斷

World Model 領域是非常百花齊放，而且還沒有完成收斂，所以我在這裡放一頁 slide，希望給大家一些我個人的（思考）。

第一個問題：World Model 本身處在一個快速（爆發）的階段，但它今天走到了哪個階段？是 GPT-2 往 GPT-3 走了嗎？不是，它今天還非常早期、完全沒有收斂，沒有一個「一統天下」的 dominant 系列出現——李飛飛跟（LeCun）就在完全不同的道路上。第二個：它會 converge（收斂）嗎？大概率也不會，因為現在還沒有哪一個道路（有）任何的優勢，大家各自解決的問題甚至都不一樣。然後：World Model 對（某個）system 是必須的嗎？可能也不是，因為 game engine 之類的在未來也會進步，並不一定它就是那個「（性）（價）比最高」的選項。然後：World Model 對 robotics（機器人）是必須的嗎？大概也不是——雖然今天很多機器人從業專家比我更了解，但我個人覺得，它並不是那麼必須。因為我們最終想做的，實際上是 V（視覺/世界）跟（LLM）的結合，但實際上這條道路上做這方面工作的人是很少的，如果你仔細去看的話，幾乎沒有。

所以最後一個問題：World Model 會把我們重新帶向 AGI 嗎？我估計有點困難。因為它如果想真的帶我們走向的話，它不能只做一個「遊戲引擎」的角色。真正走 World Model 這條（路），如果能夠把我們帶向比 LLM 更高的（智能），那一定是 LLM 跟 World Model 兩者合一了——那麼你就像我們人類：我們在做規劃的時候，並不會顯式地區分「我腦子裡哪一部分是關於這個世界的認知、哪一部分是我的 planning」，它其實也是一種「（認知）（行動）一體」的狀況。這個狀況是我們高效的重要來源、是我們靈活的重要來源，而靈活是智能的一個本質表（現）。如果你還是（把它們割裂）放在這裡的話，大概你走不通——而這方面的工作也非常少。所以 World Model 後續的發展，我們拭目以待，也許它不應該（走）這麼（（割裂的路）。

## 六、哲學結論：世界是事實的總合，而非事物的總合

所以（到）最後——我想，人到中年，除了很難避免談論國際政治，我也開始變得有點抽象、看點哲學之類的（，這也是）大（語言）模型從業者的緣故吧。所以我看了一點維根斯坦（Wittgenstein）關於「語言／思維邊界」的理論，我覺得解釋力非常強。因為我之前在百川（智能）工作那兩年，我們那時候每天加班，就在想怎麼把模型的能力去（不斷提升）——（每天都能）看到（新的）技術進步。但實際上，它不是（本質）：大家每天會有很多新的（消息）、會有很多新的故事，但你感覺到它們其實很淺，沒有一個很深層的思考在講。所以拋開（那些）（喧囂）（的）東（西），我們重新回到（本質的）視角。

過去幾年的發展，可以說 scaling law 這個神話已經破滅了。「學醫救不了中國人」，scaling law 也救不了（AGI）。scaling law 過去幾年走了三個（階段）——大家應該對這個都很熟悉了：先在 pre-train（預訓練）的階段去做 scaling，更多的數據、更多的卡、更大的架構，我們就可以練得更強；然後（這條路）不行了之後，我們開始走 post-train、走 RLVR（可驗證獎勵的強化學習），走各種各樣「可以驗證」的——走數學、走代碼，這又（撐）了大概一年半年的（命）；接著這也（走）不（下去）之後，我們又開始走 test-time（compute），瘋狂地拉長 CoT（思維鏈）的過程，然後效果也確實更高了。但你說再走到今天，你還能有什麼可以 scale 的地方呢？我想不出來，我感覺所有可以 scale 的對象（幾乎）已經全部都 scale 完了。

所以 scaling（走到）今天這條路的話，那就促使我們去想：為什麼？為什麼它沒有辦法（讓損失）繼續下降？雖然各個大公司跟我個人的觀點有些不同——比如（有些人，像 Noam 這樣的）今天還在堅持說「我這個舊的道路會走向 AGI」；但是大家可以看，他們（公司）離職的人，比如 O1 的（核心研究者，Jerry T…），他去年、在前幾（個）月離開了 OpenAI，他的理由就是「我很難在 OpenAI 再去做這種新的、創新的研究了」。這是他們裡面的研究人員真正的（心聲）。

所以我就在想，從「語言」的角度來解釋一下：為什麼 LLM 今天發展不下去了？有什麼東西是 LLM 沒有辦法處理、但又是對於智能來說非常關鍵的組成部分？

首先，模型只能處理「離散化」的對象——一個對象、一個制度、一個過程，只要它能穩定地編碼進去，模型就可以學習了。但是那些連續的物理耦合、身體技能、隱性（意）會知識、局部（技）會，這些模型是沒有辦法直接掌握的。二是一個非常直接的結論：我們人類有時候會說「我想明白了，但是我說不出來」；但是 LLM 一定是「他能說出來啥、他就想啥」——它其實不存在「思維跟 saying（言說）」之間的邊界，因為它思維的原料，不像我們還有其他的思維方（式）：它的推理草（稿）、中間狀態，本質上都是外顯的符號結構，所以它的「思維」就是「問題表（示）上的狀態轉移」。再就是：模型的邊界，是「訓練語料與表示體系」的邊界——就像（維根斯坦說的）「我語言的界限意味著我世界的界限」：我沒有、我無法去講的那個部分，我也沒有辦法去思維、沒有辦法去認識。那麼可以（對應）到 LLM，它的限制就是模型訓練數據的界限——就是一個模型可以了解的事件（範圍）。

（講）完這個限制之後，我想推薦一個十多年前的 blog，叫《Neural Networks, Types, and Functional Programming》，這是 Chris Olah 的一個 blog。他在這裡面介紹了一個很核心、非常有趣的觀察：functional programming（函數式編程）裡面的一些基本操作——fold、unfold、map 之類的——跟 neural network 裡面的基本操作，兩者完美地（對應）。這篇文章出來的時候 Transformer 還沒有發表，但他當時觀察到這個之後，做了很多很漂亮的對應。我覺得今天他這個理論的解釋力，比今天我看到其他講 Harness（的框架）要好得多。所以我今天會主要遵循他的思路去講：模型、或者說 neural network，它本質上是一種 pure function，是 functional programming 的 pure function。

這個（人）本身也非常有意思，大家可以去看一下他的 blog。他沒上大學，高中沒畢業就加入了 Google，第一個項目是 TensorFlow；然後後來覺得（在）Google（做得）不（夠有）影響（力），就去跟（大家一起創立了 Anthropic）。所以他很多的觀察非常（超前），而且他的觀察今天仍然在持續地影響（我們）。

所以我想用 functional programming 來重新講一下 Harness：neural（network 的）行為可以（對應）到 functional programming 裡面的 pure function——它本身是 stateless（無狀態）的，（同樣的輸入）（跑）多少次（，）（結果都一樣，）（雖然）因為它是採樣得到的（有隨機性）。所以這個整體——嚴格的 context 管理、memory 系統這些，其實跟 immutable function、immutable data structure 完全（對應）；（而）簡（單）（的）（回滾/複合）之類（也能對應上）。歷史上從沒有哪個 neural network 達到 LLM 這樣如此廣泛的應用、產生如此大的一個（影響）。

然後我們就會發現：我喜歡用（函數式編程）這個（框架）來解釋這個（現象），能夠更好地有一些 insight。之後我們在想——為什麼在技術發展的歷史上，不同時期的、風馬牛不相（及）的技術：pure function 跟 immutable data structure 之間的關係，跟今天 model 跟 memory system 之間的關係，有如此高的相似性？這種相似性是不是有更深層的機制導致的？就像 Wigner（維格納）1960 年講的——為什麼我們純數學內部發展的這些結構，既（能）準確地描述物理世界？這個巧合本身就不是那麼自然。它裡面是不是有些更深的 insight，我們應該去思考一下。

所以第一個躍入我腦海的論斷，就是維根斯坦（的）——「這個世界是事實的總合，而非事物的總合。」棋盤上的棋子是「事物」，然後（山有）山、（河有）河流，這些都是事物；然後「白（棋）在 d4、黑（棋）在 g8」這樣的佈局才是「事實」——這些是一些已經成立的情況。現代的 LLM，它已經在很大程度上內化了「事物的總合」：所有基本的元素、詞語、圖像巴拉巴拉這些東西，通過海量的預（訓練）跟對齊，它已經把世界的基本元素壓到參數裡面去了。某種程度上，這個模型就是一個「巨大的對象詞典和模式壓縮（品）」。但是模型對「事物」的把握，並不等於它對「事實」的把握。它對「什麼是合同條款」這些東西很清楚，但是它不知道「哪一筆付款已經到（賬）、哪個授權已經生效、哪個版本的代碼已經正式合（入）、哪些主體要承擔責任」。它非常（清楚）世界有哪些元素，但未必能夠可靠地掌握「世界中到底哪些情況成立」。

所以我想最後回到我的標題，用維根斯坦的論斷去講「模型之外」到底有什麼。

**首先，模型之外有「持久化的、公共的狀態系統」。** 模型可以讀取這些系統、也可以幫助人類操作，但它不可以用一個參數來取代這些系統——就是說，LLM 仍然是一個 pure function。

**其次，是能夠產（生）制度效（力）的行動結構**：（簽署、）審計，通過這些它都可以做；但在這個過程當中，不是「模型夠不夠聰明」的問題，而是說它沒有制度身份、沒有法律資格。比如說，OpenClaw 可以被允許操作武器嗎？它擔（得）起這個（責任）嗎？我們只要想一想這個問題，答案就很明顯——一定（不）行。

**然後是模型「（呈）現—接觸—執行—測量」的這個反（饋）（閉）環**：模型可以生成計劃（只是現象），但它不能以（模型）內部的（想法）讓世界來符合（它）；反過來，是真實世界糾正世界模型，而不是世界模型讓世界去（順從）。

**最後，是像多主體形成的共識、博弈，以及市場、談判、組織、（治）理**：事實不是被「發現」的，而是在整個人（類）社會的活動當中，充（分）協商、構造出來的。模型是一個參與者，但它不是「機制本身」。尤其是經濟活動當中，事實經常依賴於（主）觀的猜測（與共識）。（純）（AI）（世）界，這是不可以「內化」代替「制度環境」的。

所以說，模型會取代人類嗎？No。也許在未來吧。謝謝大家。

## 尾聲（補充）

我最後再講一點（題外話）。昨天我跟我（愛人）兩個去產檢，然後我把產檢的結果丟給了它（AI），讓它幫我去做分析。然後（有人）問我：為什麼（你）選（美國廠商）不選國內廠商？我說：並不是因為我覺得美國人有更高的道德底線，而是因為美國的（大）廠想給我（打）騷擾電話會比較困難，我可能對他們（更放心）（一）（點）。

所以這個是我（借用/改編）的一句話（——套用「學醫救不了中國人」）：我勸大家去讀一點哲學，免得受模型公司的 PUA。因為你就看，我們當（今）世界上最強的（幾）個模型，它的掌門人都是什麼人：一個是撒謊成性的 Altman；還有另外一個自大狂（Anthropic 的 Dario）。今天早上（他們）才把（那個）強制要求各個用戶（實名認證）——就是他的傲慢已經（溢）出屏幕了，而且還是個反華（的），（我）沒有辦法去用 Claude。唯一還稍微好一點點的（Google），在競爭中今年年初起來（一）點，然後現在又下去了；然後他們自己也僱傭了哲學家（Henry Shevlin，加入 Google DeepMind）去真正認真地研究「AI 與人的關係」。而另外兩（人）都認為他們自己就（能）——他們可以對人類的未來去負責。實際上我覺得完全不是的。我們作為一個自尊的智慧生物，應該把「思考」這個部分的權利，牢牢握在我們自己的手裡，而不是交給任何一家模型公司的（掌門人）、讓他們代替我們來決定未來到底怎麼樣。好，謝謝。
